About this Java project

This is a learning project, not a real bank. It uses Java classes, objects, loops, operators, if-else, methods, arrays, encapsulation, inheritance, polymorphism, abstraction, and constructors.

Accounts are stored in server memory only. Data is lost when the server restarts. Do not use a real banking PIN or personal information.
